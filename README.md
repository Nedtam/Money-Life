# 理財人生 · 18 → 28（網頁版）

手機豎屏網頁小遊戲。玩家由 18 歲玩到 28 歲，每年遇一個同錢有關嘅情境，四揀一，十年後得一個稱號。
冇登入、冇後台，記錄存喺瀏覽器 localStorage。

## 點開

**喺部機度直接開：**
```bash
cd 07-游戏
python3 -m http.server 8123
```
然後瀏覽器開 `http://127.0.0.1:8123`。
手機同一個 Wi-Fi 就開 `http://<你部機嘅內網 IP>:8123`。

**唔想開 server 都得：** 直接 double click `index.html`。事件庫用 `<script>` 載入（唔係 fetch），所以 `file://` 開得；localStorage 亦用得。

## 檔案

```
index.html          七個畫面嘅骨架
style.css           像素風 UI（深藍＋金、硬邊、雙層描邊）
app.js              遊戲邏輯（數值、抽事件、結算、結局、分享卡）
data/events.js      事件庫 110 張（window.GAME_EVENTS）
assets/end/*.svg    17 張結局插圖（每個稱號一張）
assets/bg-*.svg     八張背景（程序生成嘅像素風 SVG：天際線／街道／銀行／辦公室／醫院／茶餐廳／CityU 校園／房間）
tools/make-bg.js    背景生成器（npm run bg 重新畫）
```

## 一局係點行

1. 開局抽「地區 × 家庭經濟 × 學費模式」，見到起始資產。
2. 第 1 年必出「住屋」（宿舍／劏房），第 5 年必出「第一份工出糧」，第 6 年必出「第一次報稅」。
3. 第 2–4 年抽大學事件，第 7–10 年抽初職事件；期間插一張大事件（疫症／金融風暴／加息／樓價／裁員／通脹）。
4. 每年：揀選項 → 見數值變化 → 年度結算（收入／固定開支／變動／年末結餘）→ 下一年。
5. 健康或心情歸零就即刻完；否則 10 年後出稱號、總分、分享卡。
6. 反悔唔限次數：揀完之後左上角個箭頭會變金色，撳一下就退返上一個選擇，可以再揀、再反悔（冇提示、冇次數限制）。事件未揀之前箭頭係灰嘅；只有結局頁嗰個箭頭係「離開」。

數字全部照 `03-游戏设计/设定-第一版.md`：
- 錢分 = clamp(round(錢 / 1000), 0, 50)；健康分 = round(健康 / 2)；心情分 = round(心情 / 2)；總分上限 150。
- 學貸：畢業一次扣 HK$60,000；無學貸：大學每年 +HK$8,000。
- 負資產年息 5%。

## 以下係我補嘅，不是設定寫死嘅（要改就改呢啲）

設定檔冇寫、但唔補就做唔到嘅地方，我揀咗一個做法；全部集中在 `app.js` 頂部 `CFG`：

1. **起始健康值**：基層 66 / 中產 72 / 富裕 76（設定只給咗心情 60/70/75）。
2. **年度結算嘅具體金額**：
   - 大學：家庭生活費按月（5,000／6,500／8,000），宿舍佔一部分，伙食交通書簿再超支 **1,200/年**——四年都要倒貼，唔會「收入支出剛好抵消」.
   - 初職：月薪 HK$18,000，月開支 HK$17,700（房租 7,500、伙食 5,500、交通 1,300、雜項 1,400、家用 2,000），年結餘 **+HK$3,600**。設定寫「每年可儲 2–4 萬」，但咁會令 28 歲人人 50 分封頂；壓到 3,600 之後，「錢」先有分佈。
   - 無學貸家庭支援：**+HK$3,000/年**（設定寫 8,000，同理壓低）。
3. **生活磨損**（設定冇）：每年結算時會扣——大學 健康 −1、心情 −1；初職 健康 −2、心情 −2。冇呢一項，隨機亂揀都會「心情 98」，三高太易。
4. **難度**（設定只在彩蛋提過，冇定義）：輕鬆／普通／地獄，只放大負面效果，倍率 0.60 / 1.00 / 1.35。
5. **「低／中／高」嘅換算**：三項分數各自除以 50 再乘 100，<40 低、40–69 中、70+ 高（即錢分 <20 / 20–34 / 35+，健康同心情同理）。
6. **大事件每局 1 張**：設定第三節寫「最多 1 個」，第六節寫「最多 2 個（個人＋時代）」；但素材只有 6 張「時代事件」型，冇「個人事件」（重病／被裁／被騙）池，所以先做 1 張。
7. **第 5 年「租金」**：冇做成事件卡（否則一年兩個事件會變 11 個），放咗喺年度結算嘅固定開支入面。
8. **`must_first_paycheck`**（第 5 年「第一份工出糧」）：事件庫冇呢張卡，我自己寫咗一張（粵語、四選項、kind 齊）。
9. **背景**：三張 UI 設計稿本身係完整 mockup，我把稿上嘅對話框／選項／面板裁走，只留街景、人物、書桌。

## 改過嘅事件（原稿錯咗，我修正咗）

有 5 個選項寫住「要花錢」但 `money` 係正數，改咗：

| 事件 | 選項 | 原本 | 改成 |
|---|---|---|---|
| `credit_01` | 再簽多筆，分期買多部機 | +1,500 | −1,500 |
| `credit_03` | 儲夠錢先買，忍多兩個月 | +1,500 | 0 |
| `credit_03` | 開多個先買後付戶口 | +1,500 | 0 |
| `spending_04` | 用先買後付，清空晒先算 | +1,000 | 0 |
| `credit_11` | 唔申請住，用 debit card 算 | +500 | 0 |

其餘「＋錢」嘅選項多數係「借錢／拖租／慳返」——手頭現金真係會多，代價寫咗喺健康同心情，冇改。

## 已知缺口（唔係 bug，係素材／設定本身嘅窿）

- **「全部都想要」彩蛋拿唔到**：每局只可反悔一次，做唔到「同一事件四條路都試過」。要做就放寬反悔次數。
- **冇「個人事件」池**：大事件 6 張全部係時代事件（疫症／風暴／加息／樓價／裁員／通脹），設定講嘅重病／被騙／意外未有素材。
- **兩條選項文案超字**：`income_10` 17 字、`income_12` 19 字（設定要求 10–14 字），已照收，按鈕會自動換行。
- **冇埋點提交接口**：設定第九節要一個提交接口，第一版只寫 localStorage（`fl_run_v1`）。
- **稱號「普通人」係預設值**：27 格入面只寫死 9 個稱號，其餘全部歸「普通人」，所以大部分人會拿到呢個。

## 驗證過咩

用系統 Chrome + Playwright 跑過（390×844 豎屏）：

- 完整一局 10 年：事件 → 結果 → 結算 → 下一年，冇 console error。
- 8 種尺寸（320×568、360×640、375×667、390×844、414×896、768×1024、橫放 844×390、1440×900）× 7 個畫面，橫向溢出 0、關鍵按鈕冇被裁。
- 隨機亂揀 30 局：**冇一局係「人生贏家」**（改之前三高太易）。
- 反悔：數值回到原狀、同一局可以反悔多次（每次退一步）。
- 學貸：第 5 年一次扣 60,000 有入帳。
- 健康歸零：即刻中斷（測到第 4 年），結束頁寫「人生停喺呢度」。
- 全選「擺爛」：拿到「逆天改命」。
- 分享卡：canvas 有畫（455KB PNG），可下載、可複製文字。
- 記憶頁：最近 10 局、稱號收集、清空記錄。
